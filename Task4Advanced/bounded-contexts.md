## Bounded Contexts — детальное описание

### 1. Медицина (Medicine) — Core Domain

| Характеристика    | Описание                                                             |
|-------------------|----------------------------------------------------------------------|
| Ответственность   | Управление лечебным процессом                                        |
| Ключевые сущности | Patient, Doctor, Appointment, Diagnosis, Prescription, MedicalRecord |
| Владелец          | Медицинский директор                                                 |
| Интерфейс         | Веб-приложение для врачей                                            |

**Контексты внутри домена:**
- **Приём пациентов (Appointment Management):** запись, расписание, пациентский поток
- **Медицинские карты (EHR):** история болезни, диагнозы, назначения
- **Поток пациентов (Patient Flow):** маршрутизация, загрузка кабинетов

### 2. Финтех (Fintech) — Core Domain

| Характеристика    | Описание                                       |
|-------------------|------------------------------------------------|
| Ответственность   | Банковские операции, кредиты, счета            |
| Ключевые сущности | Account, Invoice, Credit, Payment, Transaction |
| Владелец          | Финансовый директор                            |
| Интерфейс         | Веб-приложение + OpenAPI для партнёров         |


**Контексты внутри домена:**
- **Банковское ядро (Core Banking):** счета, балансы, проводки
- **Платежи (Payments):** обработка платежей, эквайринг
- **Кредитование (Credit):** заявки, скоринг, договоры
- **Комплаенс (Compliance):** отчётность перед ЦБ, AML/KYC

### 3. ИИ-сервисы (AI Services) — Core Domain

| Характеристика    | Описание                                                |
|-------------------|---------------------------------------------------------|
| Ответственность   | Анализ медицинских данных с помощью ML                  |
| Ключевые сущности | Model, AnalysisRequest, AnalysisResult, TrainingDataset |
| Владелец          | CTO / Data Science Lead                                 |
| Интерфейс         | gRPC API для внутренних сервисов                        |

**Контексты внутри домена:**
- **Анализ изображений (Image Analysis):** МРТ, КТ, рентген
- **NLP-обработка (NLP Service):** анализ текстов диагнозов
- **ML-модели (ML Models):** версионирование, деплой, мониторинг

### 4. Клиенты и партнёры (CRM) — Core Domain

| Характеристика    | Описание                                   |
|-------------------|--------------------------------------------|
| Ответственность   | Управление данными клиентов и контрагентов |
| Ключевые сущности | Customer, Partner, Contract, Consent       |
| Владелец          | Директор по маркетингу                     |
| Интерфейс         | Веб-приложение + API                       |

**Контексты внутри домена:**
- **CRM:** профили клиентов, история взаимодействий
- **Customer 360:** единое представление клиента по всем доменам
- **Контракты (Contracts):** договоры с юрлицами, согласия на обработку данных

### 5. Персонал (Staff) — Supporting Domain

| Характеристика    | Описание                                     |
|-------------------|----------------------------------------------|
| Ответственность   | Управление персоналом клиник                 |
| Ключевые сущности | Employee, Schedule, Qualification, Timesheet |
| Владелец          | HR-директор                                  |

### 6. Инвентаризация (Inventory) — Supporting Domain

| Характеристика    | Описание                                          |
|-------------------|---------------------------------------------------|
| Ответственность   | Учёт оборудования и медикаментов                  |
| Ключевые сущности | Equipment, Medication, StockItem, Supplier, Order |
| Владелец          | Операционный директор                             |

### 7. Аналитика (Analytics) — Generic Domain

| Характеристика    | Описание                                    |
|-------------------|---------------------------------------------|
| Ответственность   | Витрины данных, отчётность, Self-Service BI |
| Ключевые сущности | DataSet, Report, Dashboard, Query           |
| Владелец          | CDO                                         |

### 8. Безопасность (Security) — Generic Domain

| Характеристика    | Описание                         |
|-------------------|----------------------------------|
| Ответственность   | Аудит, авторизация, комплаенс    |
| Ключевые сущности | User, Role, Permission, AuditLog |
| Владелец          | CISO                             |

## Отношения между контекстами

| Источник → Приёмник       | Тип связи                | Шаблон интеграции                 |
|---------------------------|--------------------------|-----------------------------------|
| Медицина → Финтех         | Асинхронная              | События (Kafka)                   |
| Медицина → ИИ-сервисы     | Синхронная + Асинхронная | API (gRPC) + События (Kafka)      |
| Финтех → CRM              | Асинхронная              | События (Kafka)                   |
| CRM → Все домены          | Асинхронная              | События (Kafka)                   |
| Все домены → Аналитика    | Асинхронная              | Потоки данных (Kafka → Data Lake) |
| Все домены → Безопасность | Асинхронная              | События аудита (Kafka)            |
