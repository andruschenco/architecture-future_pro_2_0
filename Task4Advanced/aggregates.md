# Агрегаты доменов

## Медицина

### Appointment (Приём)
| Поле           | Описание                                                       |
|----------------|----------------------------------------------------------------|
| **Границы**    | Запись пациента к врачу                                        |
| **Корень**     | `Appointment`                                                  |
| **Инварианты** | Дата не в прошлом, врач свободен, пациент не заблокирован      |
| **События**    | `AppointmentCreated`, `AppointmentCancelled`, `PatientArrived` |
| **Ключ**       | `appointment_id`                                               |

### Diagnosis (Диагноз)
| Поле           | Описание                                        |
|----------------|-------------------------------------------------|
| **Границы**    | Результат осмотра врача                         |
| **Корень**     | `Diagnosis`                                     |
| **Инварианты** | Привязан к Appointment, врач имеет квалификацию |
| **События**    | `DiagnosisCompleted`                            |
| **Ключ**       | `diagnosis_id`                                  |

### Prescription (Назначение)
| Поле           | Описание                                    |
|----------------|---------------------------------------------|
| **Границы**    | Назначенное лечение, лекарства, процедуры   |
| **Корень**     | `Prescription`                              |
| **Инварианты** | Привязан к Diagnosis, не просрочен          |
| **События**    | `PrescriptionCreated`, `PrescriptionFilled` |
| **Ключ**       | `prescription_id`                           |

## Финтех

### Invoice (Счёт)
| Поле           | Описание                                               |
|----------------|--------------------------------------------------------|
| **Границы**    | Счёт за медицинские услуги                             |
| **Корень**     | `Invoice`                                              |
| **Инварианты** | Сумма > 0, привязан к Appointment                      |
| **События**    | `InvoiceCreated`, `PaymentProcessed`, `InvoiceOverdue` |
| **Ключ**       | `invoice_id`                                           |

### Credit (Кредит)
| Поле           | Описание                                            |
|----------------|-----------------------------------------------------|
| **Границы**    | Кредитный договор                                   |
| **Корень**     | `Credit`                                            |
| **Инварианты** | Скоринг пройден, сумма в лимитах                    |
| **События**    | `CreditApplied`, `CreditApproved`, `CreditRejected` |
| **Ключ**       | `credit_id`                                         |

## ИИ-сервисы

### AnalysisRequest (Запрос анализа)
| Поле           | Описание                                                    |
|----------------|-------------------------------------------------------------|
| **Границы**    | Запрос на ML-обработку медицинских данных                   |
| **Корень**     | `AnalysisRequest`                                           |
| **Инварианты** | Прикреплён файл DICOM/текст, указан тип анализа             |
| **События**    | `AnalysisRequested`, `AnalysisStarted`, `AnalysisCompleted` |
| **Ключ**       | `analysis_id`                                               |

## CRM

### Customer (Клиент)
| Поле           | Описание                                               |
|----------------|--------------------------------------------------------|
| **Границы**    | Единый профиль клиента (пациент + заёмщик)             |
| **Корень**     | `Customer`                                             |
| **Инварианты** | Уникальный email/телефон, согласие на обработку данных |
| **События**    | `CustomerCreated`, `CustomerUpdated`, `CustomerMerged` |
| **Ключ**       | `customer_id`                                          |
