## Этапы внедрения

### Этап 1: Пилот (0–6 месяцев)

**Цель:** Запуск Data Mesh в домене Fintech, отработка подходов.

| Активность                    | Результат                         | Участники                      |
|-------------------------------|-----------------------------------|--------------------------------|
| Выделение bounded contexts    | Определены границы доменов        | Архитектор, Data Product Owner |
| Запуск Managed Kafka          | Работает событийная шина          | Platform Engineer              |
| CDC из легаси DWH в Kafka     | Данные текут в новый конвейер     | Data Engineer                  |
| Пилотная витрина в ClickHouse | Первый отчёт за минуты, а не часы | BI-аналитик                    |
| Data Contract для Fintech     | Стандарт качества данных домена   | Data Product Owner             |
| Обучение команды (Kafka, DDD) | 80% команды прошли обучение       | Все                            |

**Метрики успеха:**
- Время формирования финансового отчёта: < 5 минут (было 2 часа)
- Количество инцидентов: снижение на 20%

### Этап 2: Масштабирование (6–18 месяцев)

**Цель:** Расширение Data Mesh на Медицину и CRM, запуск Self-Service.

| Активность                       | Результат                                  | Участники                 |
|----------------------------------|--------------------------------------------|---------------------------|
| Домен Медицины в Data Mesh       | Clinic, EHR, Inventory как Data Products   | Data Engineer, Архитектор |
| Анонимизация медицинских данных  | Пайплайн деперсонализации перед аналитикой | Data Engineer             |
| Trino для федеративных запросов  | Единый SQL-доступ ко всем доменам          | Platform Engineer         |
| Data Portal (DataHub + Superset) | Self-Service BI для аналитиков             | BI-аналитик               |
| Data Catalog                     | Все доменные датасеты описаны              | Data Governance Lead      |
| Anti-Corruption Layer            | Легаси интегрированы через ACL             | Data Engineer             |

**Метрики успеха:**
- 3 домена работают в Data Mesh
- 50% отчётов строится через Self-Service
- Время подключения нового источника: < 1 неделя

### Этап 3: Поддержка и оптимизация (18–36 месяцев)

**Цель:** Отказ от легаси, новые домены, георасширение.

| Активность                        | Результат                                  | Участники                         |
|-----------------------------------|--------------------------------------------|-----------------------------------|
| Вывод SQL Server из эксплуатации  | Легаси DWH отключён                        | Data Engineer, Архитектор         |
| Вывод Camel ESB                   | Все интеграции через Kafka                 | Platform Engineer                 |
| Новый домен «Фарма»               | Подключён через Kafka, свои витрины        | Data Product Owner, Data Engineer |
| Георепликация (Kafka MirrorMaker) | 3 региона работают независимо              | Platform Engineer                 |
| Data Observability                | Мониторинг качества данных во всех доменах | Data Governance Lead              |

**Метрики успеха:**
- 5+ доменов в Data Mesh
- 100% отчётов через Self-Service
- Легаси полностью выведены
